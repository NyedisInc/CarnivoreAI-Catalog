# carnivore catalog

the skills, themes, plugins and mods that the carnivore app installs. browse them at https://catalog.carnivore.ai.

## folders

each item lives at `<folder>/<publisher>/<name>/`.

- `skills/` instructions an agent loads when they apply
- `themes/` a look for the app
- `plugins/` plugins, both those that add commands and agents and those that run beside the app
- `mods/` small additions to the app's own screens

## use it with claude code

```
/plugin marketplace add NyedisInc/CarnivoreAI-Catalog
```

## adding an item

items are submitted from the carnivore app. each one is checked and signed before it is listed. this repository is
read-only, so it takes no pull requests.
